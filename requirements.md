# Project Requirements & Dependencies

To set up the environment and reproduce the results of this project, install the following required dependencies:

```bash
pip install -r requirements.txt
```

### Dependency List:
- `tensorflow>=2.10.0` : Core Deep Learning framework for model building and training
- `numpy>=1.23.0` : Numerical operations and array manipulation
- `matplotlib>=3.5.0` : Plotting loss curves, accuracy plots, and visualizations
- `seaborn>=0.12.0` : Heatmaps and confusion matrix generation
- `scikit-learn>=1.1.0` : Stratified train/val/test splits and classification metrics
- `jupyter>=1.0.0` : Interactive notebook environment
- `kaggle>=1.5.12` : API to download the Rice Image Dataset directly
